Install

৩ মিনিটে ইনস্টল

Play Store লাগবে না — সরাসরি APK ইনস্টল করুন।

APK ডাউনলোড করুনউপরের “APK ডাউনলোড” বাটনে চাপ দিন (v3.0.22)।
“Unknown apps” অনুমতি দিনSettings → Apps → Special access → Install unknown apps → আপনার ব্রাউজার → Allow।
ফাইলটা খুলে Install চাপুনডাউনলোড ফোল্ডার থেকে Ajijul-Ai-v3.0.22.apk ওপেন করুন।
Gemini API key দিনঅ্যাপ খুলে Settings → aistudio.google.com/apikey থেকে ফ্রি key নিয়ে পেস্ট করুন, তারপর “Key যাচাই” চাপুন।
মাইক অনুমতি দিন“Ajijul” বলে ডাকুন বা মাইক বাটনে চাপ দিন — কথা বলা শুরু করুন।
নোট: অ্যাপটি নিজে কোনো API key শেয়ার করে না — Gemini (আর চাইলে Groq / ElevenLabs) key আপনার নিজের লাগবে। Key শুধু আপনার ফোনেই সংরক্ষিত থাকে।
FAQ

সাধারণ প্রশ্ন

ফ্রি?

হ্যাঁ, অ্যাপ সম্পূর্ণ ফ্রি। শুধু Gemini API key লাগবে (Google AI Studio-তে ফ্রি টিয়ার আছে)।

ইন্টারনেট লাগবে?

ভয়েস ও উত্তর Generation-এর জন্য হ্যাঁ। Wake word ডিভাইসেই চলে, ইন্টারনেট ছাড়াও।

My data কোথায় যায়?

কথা Gemini-তে যায় (আপনার নিজের key দিয়ে)। API key ফোনের prefs-এ শুধু লোকালি থাকে।

কিছু কাজ করছে না?

Settings → “Key যাচাই” দেখুন। বিস্তারিত লগ: Download/Ajijul/debug.log।
